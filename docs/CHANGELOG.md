# 📝 История изменений Guguverse Minecraft Launcher

Все важные изменения в проекте будут описаны в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

---

## [1.0.0] - 2026-10-25 (Первый релиз)

### ✨ Добавлено
*   Создан базовый интерфейс лаунчера на CustomTkinter (в стиле Guguverse Studios).
*   Добавлено поле для ввода никнейма с сохранением в конфиг (`launcher_config.json`).
*   Добавлен выпадающий список для выбора версии Minecraft (от 1.8.9 до 1.21).
*   Реализовано автоматическое скачивание выбранной версии игры и нужной версии Java.
*   Добавлен запуск игры в офлайн-режиме (без необходимости лицензии Microsoft).
*   Создана структура папок проекта (разделение на `src`, `ui`, `core`, `utils`).
*   Написана документация: `README.md`, `INSTALL.md` и этот `CHANGELOG.md`.
