# 🛠️ Инструкция по установке Guguverse Minecraft Launcher

Этот гайд поможет вам установить и запустить лаунчер от **Guguverse Studios**. 
Лаунчер работает на Python и автоматически скачивает нужную версию Minecraft и Java.

---

## 📋 Что вам понадобится

1. **Компьютер** (Windows, macOS или Linux).
2. **Интернет** (для скачивания игры и библиотек).
3. **Установленный Python** (версия 3.10 или выше).

---

## 🚀 Шаг 1: Установка Python

Если у вас еще нет Python:
1. Зайдите на официальный сайт: [python.org/downloads](https://www.python.org/downloads/)
2. Скачайте последнюю версию для вашей ОС.
3. Запустите установщик.
4. **ВАЖНО:** При установке поставьте галочку **"Add Python to PATH"** (Добавить Python в PATH). Если этого не сделать, лаунчер не запустится.

---

## 📥 Шаг 2: Скачивание лаунчера

1. Зайдите на страницу релизов (Releases) репозитория Guguverse-Minecraft-Launcher.
2. Скачайте архив с исходным кодом (Source code .zip).
3. Распакуйте архив в удобную папку (например, на Рабочий стол).

---

## 📦 Шаг 3: Установка библиотек

1. Откройте папку с лаунчером.
2. В адресной строке проводника напишите `cmd` и нажмите Enter (откроется командная строка).
3. Введите команду:
   ```bash
   pip install -r requirements.txt
